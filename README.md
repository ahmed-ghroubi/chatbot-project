
# Nova Chat

Nova Chat is a modern AI chatbot portfolio assistant.  
It can answer questions about Ahmed Ghroubi's skills, projects, education, experience, and also general questions.

The project uses:

- Node.js
- Express
- Gemini API
- Groq API
- HTML, CSS, and JavaScript

---

## Features

- Modern responsive chatbot UI
- Login page
- Chat history with local storage
- Delete individual conversations
- Clear all conversations
- Model selector
- Streaming AI responses
- Recruiter-focused suggestions
- Portfolio assistant for Ahmed Ghroubi

---

## Requirements

Before running this project, make sure you have:

- Node.js installed
- npm installed
- A Gemini API key
- Optional: a Groq API key
